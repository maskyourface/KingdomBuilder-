# 中世纪王国建设（KingdomBuilder）

Godot 4.7（GDScript 2.0）制作的 2D 王国建设原型，中文界面，地图、人物、界面全部由代码绘制（占位色块美术）。
核心玩法已闭环：**开局世界设置**（地图大小/地形/资源丰度/种子）→ 生产链 → 建筑升级 →
时代进阶 → 幸福度日结 → 四季与冬季取暖 → 随机事件 → 强盗袭击 → 市场金币 → 贸易站 →
建成城堡加冕为王。村民带个体特长，派谁去哪是真决策。
**57 座建筑、24 种资源、4 种交通方式**，每个时代都有对应的军事 / 经济 / 民生建筑。

## 如何运行

- 用 **Godot 4.7** 打开本目录（`project.godot` 所在目录），按 **F5** 运行（窗口 1280×720，GL Compatibility 渲染器）。
- 导出：项目已带 Windows Desktop 导出预设（`export_presets.cfg`），导出路径 `./中世纪王国建设.exe`。

## 操作

### 菜单与全局

- 启动进入主菜单（游戏暂停、HUD 隐藏）：有存档时主按钮为「继续游戏」（读最新档）并另给「新游戏」；无存档时为「开始游戏」。另有「读取 / 设置（占位）/ 结束游戏」。
- **开新一局必经「缔造新世界」面板**（主菜单「新游戏」，或无存档时的「开始游戏」）：

  | 板块 | 选项 |
  |---|---|
  | 地图大小 | 小片领地 40×40 / 标准王国 56×56 / 辽阔疆域 76×76 |
  | 地图类型 | 大平原 / 密林 / 湖沼之乡 / 高地丘陵 |
  | 资源丰度 | 贫瘠 ×0.6 / 适中 ×1.0 / 富饶 ×1.5 |
  | 世界种子 | 留空 = 每局随机；填数字则同一张地图可复现（也可点「随机」掷一个） |

  地形不是换皮：湖沼之乡 19% 水域把陆路切碎（**桥**变刚需），高地丘陵 17% 山地 + 密集铁矿
  （**山道**变刚需），大平原森林稀少（**植树场**变刚需），密林平地零碎（要先砍出城区）。
- **ESC**：放置模式中先取消放置 → 有拆除红框先消红框 → 否则开关菜单。菜单内 ESC：子面板退回主面板，主面板则返回游戏（长按不重复触发）。
- **Space**：1× → 2× → 4× → 1× 循环倍速，弹出提示，时间栏带 ×N 徽标；开菜单 / 读档 / 新游戏会复位为 1×。
- **WASD** 平移镜头（物理键位，非 QWERTY 布局可用），**滚轮** 缩放（0.4~3.0 倍）。

### 顶栏（两行）

| 位置 | 内容 |
|---|---|
| 第一行 | 时间（入冬前 ≤5 天显示「距冬季N天」，冬季显示「（冬季中）」，倍速带 ×N）· 时代与阶段目标（有无房村民时前缀「⚠ 先建小屋安置村民」）· 人口/空闲/无房 · 幸福度（<40 变红）· 按钮：建造菜单 / 村民列表 / 概览 / 日志 / 一键招满 / 保存 / 读取 |
| 第二行 | 「月报」按钮 + 资源栏：只列**当前相关**的资源（木材/食物/面包/石料/金币常驻，其余有库存或本月动过才占位），每项后挂**月度净额**（▲6.0 / ▼1.5）。24 种资源全列会把顶栏挤爆，完整口径看月报 |

### 建造 / 拆除 / 查看（鼠标）

- **建造菜单**：左侧列表（带滚动，未解锁时代的建筑置灰并标注「XX解锁」）；选中后面板保持打开，可连续换建筑。
- **左键放置**：预览绿=可放、红=不可放（不可放或买不起不扣资源）；放置即扣费，生产/功能建筑自动招 1 名工人（兵营除外，需手动指派）。**土路、小屋、麦田、水井、城墙、城门**支持按住左键拖动连放。
- **右键**：选中建筑时=取消选中；未选中时=拆除——右键点建筑先显示红框（按整座建筑占地高亮）做**两段确认**，再按同一座建筑才真拆（退还一半造价，工人/住户就地解除，拆兵营则卫兵当场退役）；右键点土路直接拆，**按住右键拖动可连续拆路**；点空地或按左键取消待确认。
- **左键查看**：未选中建筑时，点村民（24px 判定半径优先）或点建筑打开详情面板。
- **放置预览带范围**：选中光环建筑（水井/村长木屋/公共浴场/教堂/酒馆/医馆）时预览光环圆圈，选中驱狼建筑（警戒哨/篝火/猎犬棚/烽火台）时预览驱狼圈，选中采集类建筑时预览方形工作窗口——**不用先盲放一次再拆**。
- 建筑详情：造价、生产配方与实时进度条、**班组效率百分比**（>100% 说明班组里有勤劳/手巧的人）、停工原因（缺原料 / 缺工人（N/M 在岗）/ 冬季停产 / 天灾停产 / 福利建筑「今日不生效」）、工人 ＋/−、住户 N/M、市场/贸易站的「昨日成交 / 昨日收购」战报、**升级按钮**（带造价与下一级收益摘要，满级隐藏）、拆除（退一半**总投入**，含历次升级）。
- 村民详情：**特长与说明**、状态与幸福度、饥饿度条、工作、住所、「解除工作」按钮；村民列表点击某行 → 镜头跳转到该村民并打开详情，列表支持「只看空闲/无房」筛选与「默认/名字/饥饿/特长」排序。
- **王国概览**（顶栏「概览」或 `T`）：存粮可撑几天、冬季整冬柴火缺口、每种资源的昨日进/出/净额、停工盘点（缺工人×3、缺原料×1…）。
- **每月收支**（顶栏「月报」或 `R`，仿群星）：**1 月 = 5 天 = 1 个季节**，取最近 5 天流水的日均 ×5。
  按食物 / 原料 / 产物 / 财富四类分节，每行 `库存 | 月进项 | 月支出 | 净额`；
  样本不满 5 天时按已有天数折算并在标题标明「样本 N/5 天」；末尾红字点名
  **按当前速度一个月内会耗尽的资源**。
- **一键招满**：按产业链优先级轮转补人（先喂饱：采集/渔/猎/麦田/牧场/养蜂 → 再供料：伐木/采石/黏土/铁矿/草药/盐场
  → 再加工：磨坊/面包/腌肉/炭窑/砖窑/冶铁/铁匠/纺织/制革/药剂/酿酒 → 最后福利与商贸 → 防御塔），
  兵营与骑士营始终需手动指派。
- 底部有常驻操作提示条；所有界面按钮不抢键盘焦点（Space 倍速不会被按钮吞掉）。
- **左下角顾问**：前 6 天走新手引导，引导毕业后自动换成状态驱动的「现在最该干什么」——
  按紧急度只报一条（告急 → 提醒 → 信息），覆盖露宿 / 断粮 / 冬季木柴不足 / 备柴倒计时 /
  幸福度偏低 / 该建篝火防狼 / 生食超保鲜线 / 有空闲村民和空岗 / 有建筑停工。

## 玩法与经济

### 时代（按人口自动进阶）

| 时代 | 名称 | 人口门槛 | 顶栏阶段目标 |
|---|---|---|---|
| Ⅰ | 拓荒营地 | 0 | 存粮备柴过冬，人口达到 15 |
| Ⅱ | 村庄 | 15 | 人口达到 40，穿上衣服，用篝火挡住狼群 |
| Ⅲ | 城镇 | 40 | 人口达到 100，满足信仰与娱乐，办起学堂 |
| Ⅳ | 城邦 | 100 | 人口达到 250，建立防御 |
| Ⅴ | 王国 | 250 | 三期建成城堡（地基→主楼→王城），加冕为王 |

升时代弹提示；人口跌落会降级（静默更新）。**袭击从时代Ⅱ开启**：时代Ⅱ~Ⅲ 是野狼（血薄、不拆墙、只叼食物与羊毛、怕篝火），
时代Ⅳ 起换成强盗（拆墙、抢住房与市场）。时代Ⅰ 留给纯建设。

### 幸福度（每天清晨逐人结算，全局值 = 全员平均）

| 条件 | 加减 |
|---|---|
| 基础 | +50 |
| 有住房 / 无家可归 | +10 / −30 |
| 昨天吃过面包（吃生食不算） | +10 |
| 挨饿（饥饿度 > 60） | −20 |
| 住所在水井光环内（半径 4 格） | +5 |
| 衣服（时代Ⅱ起）：有 / 无 | +10 / −10 |
| 信仰（时代Ⅲ起）：受教堂光环覆盖 / 未覆盖 | +10 / −5 |
| 娱乐（时代Ⅲ起）：酒馆服务到 / 没排到 | +10 / −5 |
| 家里没柴烧（冬季取暖失败） | −15 |
| 特长「乐观」 | +8 |
| 城堡（按期数） | 全体 +4 / +7 / +10 |
| 袭击士气：击退（无人被抢）/ 每被抢 1 批（封顶 −20） | +5 / −10，持续 2 天 |

最后钳制到 0~100。光环按「住所到建筑的距离」判定，无家可归者吃不到任何光环；教堂/酒馆当天白天必须有人到过岗才生效；袭击当天信仰/娱乐的缺席惩罚豁免（记 0 不记 −5）。

- **幸福 ≥ 70**：全部生产 ×1.2，且移民提速（见移民）。
- **幸福 < 40**：每天走 1 人（软失败：优先无房者，其次幸福最低者，卫兵豁免；人口 > 1 才生效），弹提示。
  **前 3 天是新手保护期**：幸福再低也不走人，只弹一条说清原因的提示（开局全员露宿 = 幸福 20，
  不设保护期会在第 1 天就走人）。

### 进食与面包链

- 饥饿度 0~100，每秒 +100/240（≈4 分钟饿满）；≥60 找吃的，进食引导 2 秒；**面包回满 100，生食只回 50，有面包优先吃面包**；饥饿到 100 饿死（各种状态——含逃难/战斗中——饿到临界都会先吃饭）。
- 链路：麦田（2 小麦/8 秒）→ 磨坊（2 小麦→2 面粉/6 秒）→ 面包房（2 面粉→2 面包/6 秒）。
- 生产通用规则：需要工人的建筑按**在岗人数比例**出产（满员满速），缺原料停工，幸福 ≥70 时 ×1.2。

### 衣服链（时代Ⅱ）

- 牧羊场（2 羊毛/10 秒）→ 纺织坊（2 羊毛→1 衣服/6 秒）。
- 每天清晨给没衣服的村民发一件（库存够才发）；一件衣服穿 **8~12 天**后磨损坏，需重新领。

### 啤酒与酒馆（时代Ⅲ）

- 酿酒坊：2 小麦→2 啤酒/8 秒。
- 酒馆：半径 5 格娱乐光环，基线服务 **8 人/天**，服务上限随时代翻倍（时代Ⅲ 8 / Ⅳ 16 / Ⅴ 32）。
- 实际服务人数 = min(覆盖村民, 服务上限, 啤酒库存×2)，**每 2 人耗 1 啤酒**；名额每天随机轮转；啤酒不足时按库存**部分服务**而不是全有全无。教堂/酒馆当天无人到岗则该建筑今天不提供信仰/娱乐。

### 市场（时代Ⅳ）与贸易站（时代Ⅴ）

市场每天清晨自动卖出富余产物换金币（白天有人到过岗才卖；详情面板显示昨日成交）：

| 项目 | 数值 |
|---|---|
| 保留线（低于不卖） | 面包 = 人口、生食 = 人口×2、衣服 = 人口、啤酒 = 10 |
| 单价（从贵到便宜卖） | 衣服 3 金 / 啤酒 3 金 / 面包 2 金 / 生食 1 金 |
| 每市场每日上限 | 20 金 |

贸易站每天清晨用金币收购（详情面板显示昨日收购）：

| 项目 | 数值 |
|---|---|
| 石料 | 2 金/个，日上限 10 个（=20 金） |
| 木材 | 1 金/个，日上限 20 个（=20 金） |
| 单站日支出上限 | 40 金 |
| 金币保底 | 库存金币 ≤ 50 时不收购（给城堡的 50 金留底） |

金币的进项只有市场出售；出口是卫兵军饷（1 金/人/天）、贸易站收购与城堡造价（含 50 金）。

### 野狼（时代Ⅱ~Ⅲ）

时代Ⅰ 是纯建设期；从时代Ⅱ 起每 5~8 天有一次狼群下山（前一天傍晚挂横幅预警，
冬季休战），数量 `min(1 + 人口/50, 4)`。

- **血 30**（强盗 60）、**移速 78**（强盗 60，逃跑的村民真跑不过）、**不拆墙**（进不去就走）。
- **只盯吃的**：牧羊场 / 采集小屋 / 渔屋 / 麦田 / 粮仓；不碰住房、不进市场。
- **战利品**：生食 `max(2, 库存/20)`；咬牧羊场时额外叼走羊毛 `max(1, 库存/10)`。引导 3 秒（强盗 5 秒）。
- **怕火**：被**篝火**照到的建筑不会被盯上；误闯进火光范围的狼当场夹尾巴跑。
- 战后士气结算、超时保险丝、存档即撤退等机制与强盗完全共用。

**篝火**（木5，时代Ⅱ，可拖动连放，半径 5 格/每级 +1.5）：
除了吓退野狼，冬季每天烧 2 木**替半径内所有住房集中取暖**——
5 户人家各烧各的要 5 木，围着一堆篝火只要 2 木。
**"把房子挤在一起"因此成为一个有实际收益的布局决策。**

### 袭击（时代Ⅳ起）

- **排期**：间隔 6~9 天随机；**前一天傍晚**（一天进度 ≥70%）挂预警横幅「明日清晨可能来袭」；袭击日等天亮现身（不在深夜偷家）。
- **强盗数量** = 2 + 人口/60（整除）；从地图边缘生成，奔向最近的住房或市场。
- **抢劫**：引导 5 秒后偷走生食 10% + 面包 10%（各至少 1），有市场时再偷金币 10%（至少 1），得手后从边缘撤离。
- **防御**：城墙 HP 60 / 城门 HP 80（村民可走、强盗不可走，强盗会拆墙突围，拆墙 15 伤/秒）；箭塔射程 6 格、12 伤 / 1.5 秒、需有人在岗、优先射血量最低的强盗；卫兵（兵营工人，最多 3 人，手动指派）HP 120、12 伤/秒、10 格内主动迎击、每天回血 40、军饷 1 金/天（发不出就地退役）。平民 8 格内有强盗就逃回家（箭塔射手与卫兵不逃）。
- **战后士气**：无人被抢 +5；每被抢 1 批 −10，封顶 −20；持续 2 天（计入幸福度）。
- **保险丝**：单次袭击最长持续 4 天，超时强制结算，防止袭击状态卡死。
- **冬季休战**：冬季不排期，已排期的顺延到开春重新随机；时代跌破Ⅳ取消待发动与预警。
- **袭击中存档或读档 = 强盗立刻撤退**（不做士气结算）；因此袭击进行中打开读取面板不会触发自动存档。

### 建筑升级

22 座建筑可升级（土路与城堡除外），详情面板「升级」按钮。**Lv2 造价 = 目录基础价，Lv3 = ×2**；
拆除退款按「建造 + 历次升级」的总投入折半。地图上等级用右上角金色角标表示。

| 加成 | 作用建筑 |
|---|---|
| 住房 +2/级 | 小屋（3 → 5 → 7 人） |
| 光环半径 | 水井 +1.5/级、教堂 +1.5/级、酒馆 +1/级 |
| 提速 + 工位 +1/级 | 采集小屋/渔屋/伐木场/麦田/采石场/磨坊/面包房/牧羊场/纺织坊/酿酒坊 |
| 工作半径 +1/级 | 采集小屋/渔屋/伐木场/采石场/植树场 |
| 日限 | 货摊 +6 金/级、市场 +10 金/级、贸易站收购预算 +20 金/级 |
| 服务人数 | 酒馆 +6 人/级 |
| 耐久 | 城墙 +60/级、城门 +80/级（升级顺带修满） |
| 伤害/射程 | 箭塔 +6 伤 / +1 格·级 |
| 工位 | 兵营 +1 卫兵/级、贸易站 +1/级 |

设计取舍：生产建筑贴着稀缺地形（森林/石林/浆果/水域）建，**升级往往比另找一块地更划算**；
住房升级不省木头但**省地皮**——把所有人挤进水井/教堂光环和城墙里才是它的价值。
每级同时 +工位，所以升级也要吃人口，不是白嫖的产能。

### 村民特长

每个村民出生即定一个特长（入档）。**派谁去哪是真决策**：勤劳/手巧的人放进瓶颈产线，
体弱的去看水井或麦田，腿快的顶远岗位。

| 特长 | 效果 |
|---|---|
| 寻常 | 没有特别之处（抽取池里约占一半） |
| 勤劳 | 干活效率 +25% |
| 手巧 | **仅在有原料投入的加工作坊**（磨坊/面包房/纺织坊/酿酒坊）效率 +35% |
| 壮硕 | 饿得慢 25%；当卫兵多 40 点血 |
| 乐观 | 自身幸福 +8 |
| 腿快 | 移动速度 +25% |
| 体弱 | 效率 −15%，饿得快 30%（约占 1/10） |

建筑详情显示**班组效率百分比** = 在岗人力之和 ÷ 满编人数；出勤与停工判定仍按人头数，
只有产速吃人力。一键招满**不看特长**（就近选人），手动挑人才有价值。

### 城堡三期工程（时代Ⅴ）

原先是"攒够 木100 石80 金50 然后点一下就通关"——中间几十分钟没有任何反馈。
现在拆成三期，每一期落成都立刻给全体幸福加成，**攒资源的过程本身有了节奏**：

| 期 | 造价 | 全体幸福 |
|---|---|---|
| 地基（放置） | 木30 石24 金10 | +4 |
| 主楼（升级 Lv2） | 木24 石19 金14 | +7 |
| 王城（升级 Lv3） | 木48 石38 金28 | +10，**落成即加冕** |

三期总价 木102 石81 金52，与旧版一次性造价基本持平（分期不涨价，logic_test 有断言守着）。
时代Ⅴ 的顶栏目标行会实时报出"城堡 N/3 期 · 下一期需要多少"。

### 学堂（时代Ⅲ）

木18 石10，2×2，需 1 名先生在岗。每天清晨点化半径 6 格内（**按住所判定**，无家可归者上不了学）
的村民，每日名额 1 人（每级 +1，半径每级 +1.5）：

- **体弱 → 寻常**（先把身子调理好）
- **寻常 → 勤劳 / 手巧 / 腿快**（学会一门手艺，随机其一）
- 已经有手艺、或壮硕/乐观的人不再进课堂——避免把全村洗成清一色的最优解。
- 名额每天随机轮转；先生当天没到岗则今天不上课。

这条把「村民特长」从**出生抽签**变成**可以长期投资的东西**：
教堂/酒馆是给幸福度加分，学堂是真的改变你的人力质量。

### 冬季取暖（柴火）

冬季每天清晨，**有住户的**房子烧柴取暖：住 ≤3 人烧 1 木，升级过的大房烧 2 木。
烧不起的房子当天挨冻，住户 −15 幸福。空屋不烧柴（避免"多盖房反被柴钱压垮"）。
顶栏「距冬季N天」连带报出需备柴 M 木/天，概览面板给整冬缺口。
**前期目标因此从"只囤粮"变成"囤粮 + 囤柴"。**

### 生食腐坏

生食库存超过 `max(人口×4, 40)` 的部分，每天腐坏 20%（冬季天冷不腐）。
面包/小麦/面粉都不腐——**"把余粮磨面烤成面包"因此成为有回报的正解**，
同时堵掉"囤两百生食然后挂机"的退化打法。保鲜线下限 40 保护开局 30 食与小村庄。

- **效果原子化**：负向资源先合并预检，任一不足整单放弃（绝不白给金币/buff）。
- **`lose` 惩罚键**：有多少扣多少，不走"买不起就整单放弃"——否则"不管它们"这种恶果选项
  会因为穷而变成免费午餐。
- **`halt {ids, reason}`**：任何事件都能点名停任何建筑，停产原因显示在详情面板。
- **全灰兜底**：事件卡是模态暂停的，若所有选项都被置灰会卡死游戏 → 补一个永远可选的
  「无能为力，听天由命」。
- 点名停产的建筑一座都没有时不弹该卡；人口为 0 时不弹（覆灭面板才是正主）。

### 移民（人口增长）

每天清晨判定，需同时满足：

- 可食库存（面包+生食）≥ max(人口×2, 4)——**冬季口粮线翻倍为人口×4**；
- 住房总容量 > 当前人口。

满足后来 1 人；**幸福 ≥ 70 第 2 人；时代 ≥ 3 第 3 人；时代 ≥ 4 第 4 人**（逐级需再有空位）。新村民落在随机一栋住房门口。开局给 5 名村民、木材 30、生食 20。

### 冬季与四季

- 现实 60 秒 = 游戏 1 天，5 天一季（春→夏→秋→冬）；白天工作窗为一天进度的 0.15~0.85（42 秒）。
- 冬季**麦田与采集小屋停产**（磨坊/面包房等照常开工，可耗库存小麦/面粉），入冬弹提示；顶栏提前 ≤5 天显示「距冬季N天」。
- 村民在土路上移动速度 +60%。

### 原料优先级

生产结算是「按节点顺序逐个从全局库存拿料，先到先得」——迭代 3 记录过的
「石料节奏陷阱」（先建的磨坊把石头抢光，面包房永远攒不齐）就是这条的后果。
与其把它藏成暗坑，不如把顺序交给玩家：需要投入原料的建筑，详情面板有
**「原料优先级：高 / 常规 / 低」**按钮，改优先级即改结算顺序（地图上用左上角小三角标出）。
小麦紧张时先喂磨坊还是先喂酿酒坊，是时代Ⅲ 一个真实的抉择。

### 资源一览（24 种）

| 分类 | 资源 |
|---|---|
| 食物 | 食物（生食）· 肉类 · 面包 · **腌肉** · 蜂蜜 · 海盐 |
| 原料 | 木材 · 石料 · **黏土** · **铁矿石** · 小麦 · 羊毛 · **兽皮** · **草药** |
| 产物 | 面粉 · **木炭** · **砖块** · **铁锭** · **铁器** · **皮革** · 衣服 · 啤酒 · **药剂** |
| 财富 | 金币 |

四条深加工链（每条都要占人、占地、占上游）：

- **狩猎线**：猎人小屋 → 肉类 + 兽皮 → 制革坊 → 皮革
- **保鲜线**：牧羊场 / 猎人小屋 → 肉类，盐场 → 海盐 → 腌肉坊 → **腌肉**（回 90 饥饿且永不腐坏）
- **重工业线**：黏土坑 + 炭窑 → 砖窑 → 砖块；铁矿场 + 炭窑 → 冶铁炉 → 铁匠铺 → 铁器
- **医疗线**：草药园 → 药剂坊 → 药剂 → 医馆（`health` 幸福光环）

**能吃的东西按「面包 100 → 腌肉 90 → 肉类 80 → 蜂蜜 60 → 生食 50」的顺序优先消耗**
（`ResourceManager.EDIBLE_RESTORE`，回复的是饥饿度）。
生食每天腐坏 20%、肉类 30%（超过保鲜线的部分）；面包与腌肉不腐——这就是加工链的意义。

**市场定价**：原料 1~2 金、中间品 2~3 金、成品 4~12 金。
每一步加工的产出总市值必须严格大于投入总市值（`logic_test[18]` 逐条硬断言，
覆盖 11 条加工链），否则派人加工就是亏本。价目表与贸易站/港口的收购价刻意不构成套利环。

### 地形 / 采集 / 建筑作用

- **地形分区**：平原（草地）是唯一建设用地；森林、水域、石林、浆果丛、**黏土滩**、**铁矿脉**是资源地块，不可建设。每种资源地形有各自的标识物（树 / 波纹 / 石笋 / 灌木红果 / 泥坑 / 锈色矿脉），平原带草簇。
- **地图生成**：两张 fBm 噪声（高程 + 湿度）+ **分位数取阈值**——世界设置里写 19% 水域就真的是 19%，
  换地形预设时地貌差异确定可见。资源地块按贴合度打分放置：浆果贴森林、黏土贴水、铁矿在山体内部。
- **开局保证**：生成末尾会在地图中部挑一块草地最密的位置清出半径 3 的**出生广场**（镜头初始对准它），
  并检查 12 格内是否有森林 / 水域 / 石林 / 浆果丛，缺哪个就在环带上补一块。
  这条把"开局不好就重开"写进了代码——不会再出现开局无处可建或没有浆果丛的死图。
- **森林循环**：伐木场每产约 10 轮（≈20 木材）砍掉工作范围（3 格）内一格森林，砍光即停产（详情面板提示「周边森林已耗尽」）；**植树场**每轮在周边草地种回一格森林——伐木+植树形成可持续木材循环。
- **工作区域可视化**：点击伐木场/植树场/采集小屋/采石场打开详情时，地图上会画出它的工作半径圈；伐木场还会高亮范围内每一格还在的森林。
- **建筑作用**：每个建筑详情面板首行显示「作用：…」（如水井=半径 4 格内住户幸福 +5；教堂/酒馆=信仰/娱乐光环；兵营=训练卫兵；贸易站=金币收购石料木材）。
- **四种交通方式**：

  | 交通方式 | 时代 | 可铺地形 | 寻路代价 | 移速 |
  |---|---|---|---|---|
  | 土路 | Ⅰ | 草地 / 耕地 / 森林 | 65 | ×1.6 |
  | 木桥 | Ⅱ | **水域** | 80 | ×1.25 |
  | 石板路 | Ⅲ | 草地 / 耕地 / 森林（**可直接覆盖土路**） | 45 | ×2.1 |
  | 山道 | Ⅳ | **石林 / 铁矿脉** | 85 | ×1.15 |

  无路一格代价 100，村民会主动绕路走更便宜的路面（代价高低与移速快慢方向一致）。
  **桥与山道改变的是连通性**：架桥前水域不可通行，架桥后可通行——**对强盗同样有效**。
  修桥就是给自己开门，这个代价刻意不做例外。右键可拆任意路面，按住右键拖动连续拆。
- **覆灭出口**：人口归零 + 没木材重建 + 无房或无存粮，连续 2 天会弹出「王国覆灭」面板（读取存档 / 新游戏 / 继续观望）；读取存档不会让死档顶进自动存档。
- **通勤调剂**：住所离工作点超过 8 格的村民，每天最多 2 人自动搬到离工作点更近的空房，不再绑死远房长途跋涉。

拆自己建筑退一半造价；被强盗拆毁不退款；拆麦田后耕地恢复草地。

## 存档（v5）

- **目录**：编辑器内运行在项目根 `saves/`；导出版在游戏 exe 同级 `saves/`。
- **自动存档**（写 `autosave.json`）时机：返回主菜单、菜单「结束游戏」、点窗口 X 关闭、游戏内打开「读取」面板（袭击进行中除外）。顶栏「保存」按钮生成新档 `存档_日期时间.json`，不覆盖自动存档。
- **原子写**：先写 `.tmp` 并校验，成功后改名顶替旧档；写盘失败旧档原样保留。覆盖自动存档前把上一份留作 `autosave.bak.json`（不显示在读取列表，界面暂无恢复入口，需要时可手动改名找回）。
- **内容**：版本号、**世界设置（尺寸/地形/丰度/种子）**、地图地形与路面类型、全部建筑（类型/位置/等级/生产进度/耐久/当日出勤/优先级）、每个村民（位置/饥饿/幸福/衣着/职业/特长/工作/住房）、资源库存、时间、加冕状态、袭击排期与士气。
- **兼容性**：版本号 ≠5 的存档（含 v4 及更早）拒绝加载，读取列表中灰显并标注「（版本不兼容）」，删除仍可用。**读档不再要求存档尺寸与当前配置一致**——按存档里的世界设置重建地图（否则换过一次世界设置就读不了旧档，那是必现的数据事故）；地形长度与尺寸不符或条目损坏的存档会被拒绝或剔除坏条目，不会崩溃。读取面板按保存时间倒序列档，可删除存档。

## 已知取舍

- **A\* 已换二叉堆**：开列表用最小堆 + 懒惰删除（O(E log V)），村民闲逛限制在身边 10 格内，避免大人口下的跨图寻路风暴。
- **住房按名义容量**：移民/人口判定只看住房容量总和，不校验实际分房结果；分房只在建筑增减时补位。
- **生产按节点序**：建筑按放置顺序逐个结算、共享全局库存，原料紧张时先建的建筑先拿料。
- **多市场共享保留线**：保留线按人口算一份，所有市场共用；每个市场各有 20 金/天上限，第二个市场边际收益递减。
- **1 家酿酒坊约养 2 家酒馆**：酿酒坊约 10 啤酒/天，时代Ⅲ满服务每馆 4 啤酒/天；时代Ⅳ/Ⅴ服务上限翻倍后单酿酒坊无法满额供应。
- **金币闭环现状**：进项是市场 / 货摊 / 港口出售（≤8 / 20 / 32 金每座每天），出口是卫兵军饷、贸易站与港口的收购、以及城堡与大学的造价；除此之外金币没有其他去向。
- **v4 旧档拒绝**：只认 v5 存档，旧档在读取列表灰显；读取面板有「恢复上次自动存档备份」按钮。
- **顶栏按相关性折叠**：24 种资源不可能都塞进一行，顶栏只显示核心 5 种 + 有库存/本月动过的，
  超宽仍会省略号截断（被截掉的永远是排在最后的深加工品）。完整口径一律看「月报」面板。
- **「每月」是折算值不是实测**：月度数 = 最近 5 天流水的日均 ×5。刚开局或刚拆完一片产线时，
  它会滞后几天才反映新的稳态——面板标题里的「样本 N/5 天」就是提醒这一点。
- **产出排行是件数口径**：`logic_test[18]` 的「每工每分钟产出」把 1 块铁锭和 1 根木材当成
  同一件东西，只能抓数量级离群，不能用来判断哪座建筑更值钱。价值比较走市场价目表。
- **桥与山道对强盗同样有效**：这是刻意的——修桥就是给自己开门。湖沼地形里
  「先架桥还是先修墙」因此成了一个真决策。
