# 中世纪王国建设（KingdomBuilder）

Godot 4.7（GDScript 2.0）制作的 2D 王国建设原型，中文界面，地图、人物、界面全部由代码绘制（占位色块美术）。
核心玩法已闭环：生产链 → 时代进阶 → 幸福度日结 → 四季 → 强盗袭击 → 市场金币 → 贸易站 → 建成城堡加冕为王。

## 如何运行

- 用 **Godot 4.7** 打开本目录（`project.godot` 所在目录），按 **F5** 运行（窗口 1280×720，GL Compatibility 渲染器）。
- 导出：项目已带 Windows Desktop 导出预设（`export_presets.cfg`），导出路径 `./中世纪王国建设.exe`。

## 操作

### 菜单与全局

- 启动进入主菜单（游戏暂停、HUD 隐藏）：有存档时主按钮为「继续游戏」（读最新档）并另给「新游戏」；无存档时为「开始游戏」。另有「读取 / 设置（占位）/ 结束游戏」。
- **ESC**：放置模式中先取消放置 → 有拆除红框先消红框 → 否则开关菜单。菜单内 ESC：子面板退回主面板，主面板则返回游戏（长按不重复触发）。
- **Space**：1× → 2× → 4× → 1× 循环倍速（暂停中按 Space = 恢复），弹出提示，时间栏带 ×N 徽标；开菜单 / 读档 / 新游戏会复位为 1×。
- **P**：暂停 / 恢复（恢复原倍速）。**B** 开建造菜单、**L** 开村民列表。
- **中键按住拖动** 平移镜头；**滚轮** 以鼠标位置为锚点缩放（0.4~3.0 倍，缩放前后鼠标下的世界点不动）。**WASD** 平移（物理键位）。

### 顶栏（两行）

| 位置 | 内容 |
|---|---|
| 第一行 | 时间（入冬前 ≤5 天显示「距冬季N天」，冬季显示「（冬季中）」，倍速带 ×N）· 时代与阶段目标（有无房村民时前缀「⚠ 先建小屋安置村民」）· 人口/空闲/无房 · 幸福度（<40 变红）· 按钮：建造菜单 / 村民列表 / 日志 / 招满 / 保存 / 读取 |
| 第二行 | 全部 10 种资源数量（木材/食物/小麦/面粉/面包/石料/金币/羊毛/衣服/啤酒） |

### 建造 / 拆除 / 查看（鼠标）

- **建造菜单**：左侧面板，顶部按 食物/资源/民生/生产/防御 五个分组 Tab 切换（当前组高亮 ▼），带滚动，未解锁时代的建筑置灰并标注「XX解锁」；选中后面板保持打开，可连续换建筑。
- **左键放置**：预览绿=可放、红=不可放（不可放或买不起不扣资源）；放置即扣费，生产/功能建筑自动招 1 名工人（兵营除外，需手动指派）。**土路、小屋、麦田、水井、城墙、城门**支持按住左键拖动连放。
- **右键**：选中建筑时=取消选中；未选中时=拆除——右键点建筑先显示红框（按整座建筑占地高亮）做**两段确认**，再按同一座建筑才真拆（退还一半造价，工人/住户就地解除，拆兵营则卫兵当场退役）；右键点土路直接拆，**按住右键拖动可连续拆路**；点空地或按左键取消待确认。
- **左键查看**：未选中建筑时，点村民（24px 判定半径优先）或点建筑打开详情面板。
- 建筑详情：造价、生产配方与实时进度条、停工原因（缺原料 / 缺工人（N/M 在岗）/ 冬季停产 / 暴雨停产 / 周边森林 N 格（将耗尽提示）/ 周边可种草地 N 格 / 福利建筑「今日不生效」）、工人 ＋/−、住户 N/M、市场/贸易站的「昨日成交 / 昨日收购」战报、拆除（退一半造价）。
- 村民详情：状态与幸福度、饥饿度条、工作、住所、「解除工作」按钮；村民列表点击某行 → 镜头跳转到该村民并打开详情。
- **一键招满**：按产业链优先级轮转补人（采集 → 渔屋 → 麦田 → 伐木 → 植树 → 采石 → 磨坊 → 面包房 → 牧羊场 → 纺织坊 → 酿酒坊 → 教堂 → 酒馆 → 市场 → 贸易站 → 箭塔），兵营始终需手动指派。
- 底部有常驻操作提示条；所有界面按钮不抢键盘焦点（Space 倍速不会被按钮吞掉）。

## 玩法与经济

### 时代（按人口自动进阶）

| 时代 | 名称 | 人口门槛 | 顶栏阶段目标 |
|---|---|---|---|
| Ⅰ | 拓荒营地 | 0 | 存粮过冬，人口达到 15 |
| Ⅱ | 村庄 | 15 | 人口达到 40，让村民穿上衣服 |
| Ⅲ | 城镇 | 40 | 人口达到 100，满足信仰与娱乐 |
| Ⅳ | 城邦 | 100 | 人口达到 250，建立防御 |
| Ⅴ | 王国 | 250 | 建成城堡，加冕为王 |

升时代弹提示；人口跌落会降级（静默更新）。袭击系统从时代Ⅳ开启。

### 幸福度（每天清晨逐人结算，全局值 = 全员平均）

| 条件 | 加减 |
|---|---|
| 基础 | +50 |
| 有住房 / 无家可归 | +10 / −30 |
| 昨天吃过面包（吃生食不算） | +10 |
| 挨饿（饥饿度 > 60） | −20 |
| 住所在水井光环内（半径 4 格） | +5 |
| 衣服（时代Ⅱ起）：有 / 无 | +10 / −10 |
| 信仰（时代Ⅲ起）：受教堂光环覆盖 / 未覆盖 | +10 / −5 |
| 娱乐（时代Ⅲ起）：酒馆服务到 / 没排到 | +10 / −5 |
| 城堡已建成 | 全体 +10 |
| 袭击士气：击退（无人被抢）/ 每被抢 1 批（封顶 −20） | +5 / −10，持续 2 天 |

最后钳制到 0~100。光环按「住所到建筑的距离」判定，无家可归者吃不到任何光环；教堂/酒馆当天白天必须有人到过岗才生效；袭击当天信仰/娱乐的缺席惩罚豁免（记 0 不记 −5）。

- **幸福 ≥ 70**：全部生产 ×1.2，且移民提速（见移民）。
- **幸福 < 40**：每天走 1 人（软失败：优先无房者，其次幸福最低者，卫兵豁免；人口 > 1 才生效），弹提示。

### 进食与面包链

- 饥饿度 0~100，每秒 +100/240（≈4 分钟饿满）；≥60 找吃的，进食引导 2 秒；**面包回满 100，生食只回 50，有面包优先吃面包**；饥饿到 100 饿死（各种状态——含逃难/战斗中——饿到临界都会先吃饭）。
- 链路：麦田（2 小麦/8 秒）→ 磨坊（2 小麦→2 面粉/6 秒）→ 面包房（2 面粉→2 面包/6 秒）。
- 生产通用规则：需要工人的建筑按**在岗人数比例**出产（满员满速），缺原料停工，幸福 ≥70 时 ×1.2。

### 衣服链（时代Ⅱ）

- 牧羊场（2 羊毛/10 秒）→ 纺织坊（2 羊毛→1 衣服/6 秒）。
- 每天清晨给没衣服的村民发一件（库存够才发）；一件衣服穿 **8~12 天**后磨损坏，需重新领。

### 啤酒与酒馆（时代Ⅲ）

- 酿酒坊：2 小麦→2 啤酒/8 秒。
- 酒馆：半径 5 格娱乐光环，基线服务 **8 人/天**，服务上限随时代翻倍（时代Ⅲ 8 / Ⅳ 16 / Ⅴ 32）。
- 实际服务人数 = min(覆盖村民, 服务上限, 啤酒库存×2)，**每 2 人耗 1 啤酒**；名额每天随机轮转；啤酒不足时按库存**部分服务**而不是全有全无。教堂/酒馆当天无人到岗则该建筑今天不提供信仰/娱乐。

### 市场（时代Ⅳ）与贸易站（时代Ⅴ）

市场每天清晨自动卖出富余产物换金币（白天有人到过岗才卖；详情面板显示昨日成交）：

| 项目 | 数值 |
|---|---|
| 保留线（低于不卖） | 面包 = 人口、生食 = 人口×2、衣服 = 人口、啤酒 = 10 |
| 单价（从贵到便宜卖） | 衣服 3 金 / 啤酒 3 金 / 面包 2 金 / 生食 1 金 |
| 每市场每日上限 | 20 金 |

贸易站每天清晨用金币收购（详情面板显示昨日收购）：

| 项目 | 数值 |
|---|---|
| 石料 | 2 金/个，日上限 10 个（=20 金） |
| 木材 | 1 金/个，日上限 20 个（=20 金） |
| 单站日支出上限 | 40 金 |
| 金币保底 | 库存金币 ≤ 50 时不收购（给城堡的 50 金留底） |

金币的进项是货摊（时代Ⅱ，≤8 金/天）与市场（时代Ⅳ，≤20 金/天）出售；出口是卫兵军饷（1 金/人/天）、贸易站收购与城堡造价（含 50 金）。

### 袭击（时代Ⅳ起）

- **排期**：间隔 6~9 天随机；**前一天傍晚**（一天进度 ≥70%）挂预警横幅「明日清晨可能来袭」；袭击日等天亮现身（不在深夜偷家）。
- **强盗数量** = 2 + 人口/60（整除）；从地图边缘生成，奔向最近的住房或市场。
- **抢劫**：引导 5 秒后偷走生食 10% + 面包 10%（各至少 1），有任何售货建筑（货摊/市场）时再偷金币 10%（至少 1），得手后从边缘撤离。
- **防御**：城墙 HP 60 / 城门 HP 80（村民可走、强盗不可走，强盗会拆墙突围，拆墙 15 伤/秒）；箭塔射程 6 格、12 伤 / 1.5 秒、需有人在岗、优先射血量最低的强盗；卫兵（兵营工人，最多 3 人，手动指派）HP 120、12 伤/秒、10 格内主动迎击、每天回血 40、军饷 1 金/天（发不出就地退役）。平民 8 格内有强盗就逃回家（箭塔射手与卫兵不逃）。
- **战后士气**：无人被抢 +5；每被抢 1 批 −10，封顶 −20；持续 2 天（计入幸福度）。
- **保险丝**：单次袭击最长持续 4 天，超时强制结算，防止袭击状态卡死。
- **冬季休战**：冬季不排期，已排期的顺延到开春重新随机；时代跌破Ⅳ取消待发动与预警。
- **袭击中存档或读档 = 强盗立刻撤退**（不做士气结算）；因此袭击进行中打开读取面板不会触发自动存档。

### 移民（人口增长）

每天清晨判定，需同时满足：

- 可食库存（面包+生食）≥ max(人口×2, 4)——**冬季口粮线翻倍为人口×4**；
- 住房总容量 > 当前人口。

满足后来 1 人；**幸福 ≥ 70 第 2 人；时代Ⅰ幸福 ≥ 60 也给第 2 人；时代 ≥ 3 第 3 人；时代 ≥ 4 第 4 人**（逐级需再有空位）。新村民落在随机一栋住房门口。开局给 5 名村民、木材 40、生食 30。

### 冬季与四季

- 现实 60 秒 = 游戏 1 天，5 天一季（春→夏→秋→冬）；白天工作窗为一天进度的 0.15~0.85（42 秒）。
- 冬季**麦田与采集小屋停产**（磨坊/面包房等照常开工，可耗库存小麦/面粉），入冬弹提示；顶栏提前 ≤5 天显示「距冬季N天」。
- 村民在土路上移动速度 +60%。

### 随机事件（时代Ⅰ起）

每 2~4 天随机排期一次，弹出**事件卡并暂停游戏**，选定后恢复并播报结果（模态卡，必须选一项）。共 7 种：流浪工匠（收留 +1 村民，需住房空位 / 给 3 食物换明日幸福 +2）、行商队（时代Ⅱ，-10 食 +12 金）、丰收的传闻（-6 食，次日全体幸福 +10）、乌云压顶（**次日麦田停产一天**；渔屋照常——"暴雨浇不干河"）、走失的羊群（+4 羊毛 或 +4 食物）、猎户来投（+1 村民）、雪中送炭（冬季限定，+6 食物）。同种事件 8 天冷却；收留类在无住房空位时置灰，买不起的选项置灰；资源不足时整单不生效（绝不"扣了钱不给货"）；人口为 0 时不弹卡；首张事件卡在第 6 天后出现（不与引导抢戏）。

### 新手引导（前 6 天，六步各带奖励）

左下角引导面板依次给 6 步：①采集小屋（贴浆果丛）②伐木场（贴森林）③拖放 3 座小屋 ④植树场（另开麦田）⑤渔屋（贴水域）⑥水井。每完成一步发一次资源奖励（食6/木6/食8/木6/食6/石3）并 toast 播报；读档恢复不补发奖励。引导面板与村民列表互斥让位，与建造菜单可同屏。

### 地形 / 采集 / 建筑作用

- **地形分区**：平原（草地）是唯一建设用地；森林、水域、石林、浆果丛是资源地块，不可建设。四种资源地形有各自的标识物（树 / 波纹 / 石笋 / 灌木红果），平原带草簇。
- **森林循环**：伐木场每产约 10 轮（≈20 木材）砍掉工作范围（3 格）内一格森林，砍光即停产（详情面板提示「周边森林已耗尽」）；**植树场**每轮在周边草地种回一格森林——伐木+植树形成可持续木材循环。
- **工作区域可视化**：点击伐木场/植树场/采集小屋/采石场打开详情时，地图上会画出它的工作半径圈；伐木场还会高亮范围内每一格还在的森林。
- **建筑作用**：每个建筑详情面板首行显示「作用：…」（如水井=半径 4 格内住户幸福 +5；教堂/酒馆=信仰/娱乐光环；兵营=训练卫兵；贸易站=金币收购石料木材）。
- **土路**：可铺进森林成为林间小径（水域与石林不可铺路，桥梁留待后续）；寻路对路面加权（65:100），村民会主动绕走土路，路上移速 +60%。
- **覆灭出口**：人口归零且可食库存低于移民闸下限（4），连续 2 天（第 1 天先弹倒计时提示）会弹出「王国覆灭」面板（读取存档 / 新游戏 / 继续观望）；读取存档不会让死档顶进自动存档。
- **通勤调剂**：住所离工作点超过 8 格的村民，每天至少调剂 2 人、空房多时按空位数放开，自动搬到离工作点更近的空房，不再绑死远房长途跋涉。

拆自己建筑退一半造价；被强盗拆毁不退款；拆麦田后耕地恢复草地。

## 存档（v4）

- **目录**：编辑器内运行在项目根 `saves/`；导出版在游戏 exe 同级 `saves/`。
- **自动存档**（写 `autosave.json`）时机：返回主菜单、菜单「结束游戏」、点窗口 X 关闭、游戏内打开「读取」面板（袭击进行中除外）。顶栏「保存」按钮生成新档 `存档_日期时间.json`，不覆盖自动存档。
- **原子写**：先写 `.tmp` 并校验，成功后改名顶替旧档；写盘失败旧档原样保留。覆盖自动存档前把上一份留作 `autosave.bak.json`（不显示在读取列表；读取面板有「恢复上次自动存档备份」按钮可直接读它）。
- **内容**：版本号、地图地形/道路、全部建筑（类型/位置/生产进度/耐久/当日出勤）、每个村民（位置/饥饿/幸福/衣着/职业/工作/住房）、资源库存、时间、加冕状态、袭击排期与士气。
- **兼容性**：版本号 ≠4 的存档（含 v3 及更早）拒绝加载，读取列表中灰显并标注「（版本不兼容）」，删除仍可用；地图尺寸/地形长度不符或条目损坏的存档会被拒绝或剔除坏条目，不会崩溃。读取面板按保存时间倒序列档，可删除存档。

## 已知取舍

- **A\* 已换二叉堆**：开列表用最小堆 + 懒惰删除（O(E log V)），村民闲逛限制在身边 10 格内，避免大人口下的跨图寻路风暴。
- **住房按名义容量**：移民/人口判定只看住房容量总和，不校验实际分房结果；分房只在建筑增减时补位。
- **生产按节点序**：建筑按放置顺序逐个结算、共享全局库存，原料紧张时先建的建筑先拿料。
- **多市场共享保留线**：保留线按人口算一份，所有市场共用；每个市场各有 20 金/天上限，第二个市场边际收益递减。
- **1 家酿酒坊约养 2 家酒馆**：酿酒坊约 10 啤酒/天，时代Ⅲ满服务每馆 4 啤酒/天；时代Ⅳ/Ⅴ服务上限翻倍后单酿酒坊无法满额供应。
- **金币闭环现状**：进项只有市场出售（≤20 金/市场/天），出口只有卫兵军饷、贸易站收购与城堡造价；除此之外金币没有其他去向，贸易站收购就是金币最大的持续出口。
- **v3 旧档拒绝**：只认 v4 存档，旧档在读取列表灰显；读取面板有「恢复上次自动存档备份」按钮。

## 测试与工具

- `python tools/static_check.py`：启发式静态检查（跨脚本调用契约、幽灵属性、目录键、存档键对称、信号契约、语法粗检），输出控制台与 `tools/static_check_report.txt`（报告为上次运行快照）。
- `python tools/economy_sim.py`：从源码公式复刻的 60 天经济离散模拟（含冬季与袭击），输出 `tools/economy_sim_report.txt`。
- **一键门禁**：`python tools/run_gate.py`——9 项检查（static_check、块结构解析、括号配平、关键文件、主场景、ext_resource、存档对称、目录干净、Godot 实机 4 套件），输出 GO/NO-GO 并追加 `tools/gate_report.txt`。**改代码前后必跑，GO 才归档新基线快照。**
- Godot 便携版随仓库放在 `tools/godot_portable/`（4.4.1，无需本机安装）；手动执行等价命令：
  - `--headless --path . --script tests/smoke_test.gd`：启动 → 开局 → 放建筑 → 派工 → 存读档 → 180 帧模拟（独立 `test_save.json`，自动删除）。
  - `--headless --path . --script tests/menu_test.gd`：主按钮 / ESC / 暂停恢复状态机链路。
  - `--headless --path . --script tests/play_test.gd`：真实开局 720 帧（开局幸福度、自动招工、跨日结算、离开机制、存读回环）。
  - `--headless --path . --script tests/logic_test.gd`：173 项断言（目录净产出、产业链配比、存档键对称、幸福度档位、A* 等价性、一键招满优先级），失败退出码 1。
